# freeVPN · 中国大陆域名后缀 (第⑤层分流规则的数据源, 每行一个后缀)
#
# 用途: 国内域名直连, 域名不进免费节点 —— 见 security.py 第⑤层。
#
# 为什么不从 geosite.dat 抄: 本机那份 geosite:cn 有 111224 条, 里面混着
# `0000f0deb5f4e6c3.com` / `000868adh1.shop` 这类噪音, 内联进产物要 1.5 MB
# 且几乎全是长尾垃圾。这里走「TLD 级 + 主流站点」两条:
#   · `cn` 一条规则就吃掉所有 .cn / .com.cn / .gov.cn / .edu.cn
#   · 非 .cn 的国内主流站点逐个列, 约 220 条
# 想加自己的站点直接往下写一行, 重新跑一轮扫描即生效(改完不用重启服务)。
#
# 注意: 被 `cn` 覆盖的 .cn 域名不必重复列。
